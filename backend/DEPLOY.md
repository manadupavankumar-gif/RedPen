# Free deployment guide

Stack (all free tiers): Aiven MySQL (database) + Render (Spring Boot backend, Docker) + Netlify or Cloudflare Pages (frontend).

## 0. Secrets first
- The old DB password and JWT secret were in `application.properties`. They are now removed.
  Local values live in `src/main/resources/application-local.properties` (git-ignored).
- If your old DB password is used anywhere else, change it.
- Get a Groq key at console.groq.com. Never commit it.
- Push ONLY the inner `backend` folder (the one with `pom.xml`) to GitHub. Check that `application-local.properties` is not in the repo.

## 1. Database: Aiven MySQL (free)
1. Sign up at aiven.io, create a service: MySQL, Free plan.
2. When it is running, copy Host, Port, User (`avnadmin`), Password, Database (`defaultdb`).
3. Your values:
   - DB_URL = `jdbc:mysql://HOST:PORT/defaultdb?sslMode=REQUIRED`
   - DB_USERNAME = `avnadmin`
   - DB_PASSWORD = the Aiven password
Tables are created automatically (ddl-auto=update).
Note: the free plan powers off after inactivity, so power it back on in the Aiven console if the app can't connect.

## 2. Backend: Render (free web service)
1. Push the repository root (the directory containing `render.yaml`) to GitHub. On Render, create a Blueprint from that repository; it sets the service root to `backend`. If creating a Web Service manually, set its Root Directory to `backend` and use Docker.
2. Enter environment variables (these are where the password is hidden, not in code):
   DB_URL, DB_USERNAME, DB_PASSWORD, GROQ_API_KEY, JWT_SECRET (auto-generated by the blueprint), CORS_ORIGINS (fill in after step 3).
3. Deploy. You get `https://resume-ai-backend.onrender.com`.
Free services sleep after 15 min idle; the first request then takes about a minute.

## 3. Frontend: Netlify or Cloudflare Pages (free)
1. Edit `frontend/js/config.js`:
   `window.API_BASE = 'https://resume-ai-backend.onrender.com';`
3. Connect the same GitHub repository (or drag and drop a built `frontend/dist` folder onto Netlify). Set the base directory to `frontend`, build command to `npm ci && npm run build`, and publish directory to `dist`.
   Do not use the Dockerfile or nginx.conf for this route.
4. Copy the site URL, then in Render set `CORS_ORIGINS` to it (no trailing slash) and redeploy.

## Local run in Spring Tool Suite
Nothing changes: the `local` profile is the default and reads `application-local.properties`.
